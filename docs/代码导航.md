# 代码导航

主顶层：`project_v57/source/user_source/hdl_source/top_tf_hdmi_audio.v`，构建顶层模块名为 `top`。
`project_v57/rtl` 中的历史版本后缀是模块接口名称，实际参与构建的文件以 `records/build/original_build.tcl` 的 `analyze -file` 列表为准，不要将整个目录中的同名模块同时导入工具。

| 关注点 | 文件/目录 |
|---|---|
| 板级接入、各流水线连接 | `source/user_source/hdl_source/top_tf_hdmi_audio.v` |
| 按键与菜单、倍速/EQ/布局设置 | `rtl/exhibit_settings_menu_v37.v`、`rtl/exhibit_select_key.v` |
| 展示状态、轮播、讲解切页 | `rtl/exhibit_control_v37.v`、`rtl/exhibit_player_v37.v` |
| 视频播放控制、时间与定位 | `rtl/exhibit_movie_transport_v39.v`、`rtl/exhibit_movie_stream_v37.v` |
| 菜单、状态文字、视频布局显示 | `rtl/exhibit_native_osd_v38.v`及顶层布局连接 |
| 旋转与开场渲染 | `rtl/exhibit_rotation_v34.v`、`rtl/exhibit_intro_*` |
| 字幕与字体 | `rtl/exhibit_caption.v`、`caption_*`、`font_*`、`label_*` |
| 音频读取和处理 | `rtl/exhibit_tf_audio*`、`rtl/exhibit_live_mix*`以及构建清单中的音频处理模块 |
| FFT与频谱绘制 | `rtl/exhibit_fft256.v`、`rtl/exhibit_spectrum_osd.v` |
| TF四位接口与文件解析 | `rtl/sd_native4_*`、`rtl/fat32_*`、`rtl/exhibit_sd_arbiter_v37.v` |
| SDRAM帧缓存 | `rtl/frame_*_v37.v`、`rtl/exhibit_frame_cache*`、`source/user_source/hdl_source/SD` |
| HDMI、PLL和厂商IP | `source/user_source/hdl_source`、`source/user_source/hdl_source/IP`、`td_project/al_ip` |
| 引脚、时序与复位约束 | `source/user_source/constraints_source`、`td_project/reset_boundary_constraints.tcl` |

表中省略的路径前缀均为 `project_v57/`。初始化数据与 RTL 同属源码交付内容，不要只复制 `.v` 文件。
